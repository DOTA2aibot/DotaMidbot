# Проверка способностей SF в игре (kimi, п.3 плана интеграции)

Короткий локальный запуск: лобби → локальный сервер → боты в свободных слотах → «Локальный скрипт».

## Чек-лист (отмечать факт, не ожидание)

- [ ] Скрипты загрузились без ошибок (консоль: нет красных lua error после старта)
- [x] Закупка: танго → варды → ветки → ботл без ступора — подтверждено 08.11 (Олег)
- [x] Прокачка: рейзы 1–4, реквием на 6 — подтверждено 07.11 (Олег)
- [x] Рейзы кастуются (разворот + каст) — подтверждено 08.11 (Олег)
- [ ] Попадание рейза совпадает с направлением взгляда героя (визуально)
- [ ] Фактический урон рейза: хватка/нехватка на добивание крипа (сравнить с EffectiveRazeDamage)
- [ ] Души Necromastery: включить MIDBOT_DEBUG_MODIFIERS = true → в консоли имя модификатора
      и stacks растут после добиваний → записать реальное имя модификатора
- [ ] Стаки дебаффа рейзов на враге: второй рейз по той же цели бьёт больше →
      записать реальное имя дебаффа из diag-лога
- [ ] Очки прокачки не копятся после 6 уровня (фолбэк тратит: feast/aura/таланты)

## Как смотреть консоль

В Dota: консоль включается клавишей `ё`/`~` (нужно включить в настройках: Расширенные →
«Включить консоль»). Либо логи: `game/dota/console.log` рядом с dota2.exe.

## Формат результата

Каждый пункт: commit сборки, время в игре, что увидел, скрин/лог при проблеме.
Неизвестные параметры (реальные имена модификаторов, точные числа урона) — отдельным списком.
