## Поведение после калибровки

- Observer: прежние окна0/5/10мин и запас с3:30/8:30; отдельная точка для каждой стороны.
- Sentry: один в стартовом закупе; окна0:00–0:30 и6:00–6:30, запас с4:30. Общая точка для сторон, только проходимая река. Для dispenser используются secondary charges и подтверждение режима перед постановкой.
- xx:45 до12мин: удалённая проверка союзных вардов. Нет Sentry, но есть предмет — следующее окно00–30. Нет предмета — покупка/обычная доставка. Нет stock/gold/достоверного API — следующая xx:45. Неизвестная покупка не дублируется. Постановка подтверждается новой своей entity и расходом заряда/item.
- Девард: только действительно обнаруженные враги-варды, сначала Sentry. Scanxx:45, окно следующей минуты00–30 до12мин. Лайновые/нейтральные крипы, герой, каст, отступление, руны и опасность выше. Перед каждым действием свежая видимость и безопасность. Полностью живой вард ожидаемо требует2удара, но смерть проверяется отдельно; fog не означает успех. Раненый вард может умереть с1удара. Повторы и время владения ограничены.
- Агрессия: Stick7+/Wand13+ известных активных зарядов усиливают существующий Raze-харасс по одному видимому настоящему герою при достаточных текущих/потенциальных ресурсах. Нет нового контроллера движения, приказов атаки или погони; обычные удары остаются Valve. Под вышкой, при слабом HP, двух врагах или неизвестных данных бонус не выдаётся.
- Заряды полезно расходуются в бою раньше15%HP. Пустой/неизвестный предмет не нажимается. Потенциальное восстановление номинальное, это не гарантия победы.
