# v0.3.31 — отдельная диагностика native rune

T039 / Artem (GPT), reviewer Олег (Kimi). Пользователь явно подтвердил диагностический запуск штатного подбора после неуспеха direct/queued.

Архив собирается отдельным tools/package_native_rune_probe.py. Основной packager и нормальные профили не переделываются. Диагностический профиль строится из tower_pressure_test, но удаляет ОБА mode_rune entry: SF и generic-глушитель. Собственный economy/runes helper заменён в архиве инертным модулем: Decide nil, GetDesire0, Think/Leave без действий. Это не динамический nil-fallback: в runtime вообще нет scripted mode_rune файлов. Native решает, куда идти и какой приказ подбора выдавать.

Остальные runtime-файлы идентичны обычной сборке, кроме явной метки laning/profile.lua. Mana shopping сохраняется (economy_enabled=true), собственная оценка доступности руны не вмешивается в pressure. Raze, PT/Stick, ward, watcher ban, покупки/курьер остаются прежними.

Меняется именно стратегия рун: собственные правила500, игнор bounty, timeout/away guards для native приказов не работают. Другие боты тоже могут начать брать руны. Это не релиз и не утверждение, что native умеет брать нижнюю воду.

Тест: новый локальный матч до4:30; оставить нижнюю водяную SF, не подбирать её самому, по возможности иметь пустой Bottle уSF. Нужны фактический подход SF к нижней воде и получение ресурса/зарядов. Если штатный режим не пойдёт за ней, тест НЕ отвечает на вопрос о работоспособности подбора. Неудачный выбор цели не равен неисправной команде подбора. Можно продолжить только пока есть разумный короткий тестовый сценарий.

Событий собственного rune_order здесь не будет; смотреть snapshot active_mode/current_action/position/items/HP/mana и ручное наблюдение. Рост Bottle вместе с исчезновением нижней воды после его подхода сильнее, чем одно исчезновение (её может взять союзник). Native может по-прежнему терять время: новые ограничения ему не приписываются.

Офлайн: сравнение всех runtime-файлов, отсутствие обоих mode_rune, инертность helper, проверка архива с запретом старого generic-глушителя; нормальные suite также запускаются. Игровое выполнение и loader не доказаны. Установленнаяv0.3.30 и main сохранены. После диагностики вернуться к обычному профилю либо отдельно проектировать точечную интеграцию, если native показал успешный подбор.
