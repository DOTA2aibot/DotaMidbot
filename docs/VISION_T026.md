## Следующий запуск: ручная калибровка

Artem выбрал сыграть союзником SF и вручную поставить один жёлтый Observer ровно
в место с фотографии. **calibration_only=true**: собственная Radiant-постановка SF
и replenishment временно выключены. Стартовый Observer остаётся; обычные spells,
items, lane movement/AA и актуальные руны работают как прежде. SF ward-mode
явно возвращает0, а собственный tactical ward executor тоже выключен — не полагаться
на nil→C++ fallback. При этом запись координат включена и не управляет героем.

`ward_entity_observed` каждые5с проверяет реальные союзные Observer entities, новый
handle пишет один раз: actualXYZ, ownerID, human_owned при доступном IsPlayerBot,
vision_radius, rawheight, расстояния до rune1/rune2 и мида, текущую teamvisibility.
Не принимает эту точку автоматически, не угадывает координаты по пикселям фото.
Несколько вардов остаются отдельными записями с владельцами/временем. Если owner API
не сообщает человека, поле unknown не превращается в доказательство человеческой
постановки; в тесте нужен один ручной Observer и сообщение Artem о времени.

Один раз пишется `ward_test_point_geometry` для прежней(-197,-1003): statusunverified,
photo_match=not_verified, plant_validity=not_tested. Это диагностическая старая точка,
НЕ разрешение автоматически ставить туда в текущем calibration run. Passable не
эквивалентно wardable (на cliff можно поставить вард), rawheight не объявляется
высотой берега по сравнению чисел enum. Team rune_visible не доказывает exclusiveLOS.

После лога этого запуска Artem (GPT) возьмёт координаты именно человеческого варда,
сверит owner/time и запишет fixed_location, затем выключит calibration_only. До этого
точка фото не считается подтверждённой. Новый матч нужен после установки пакета.
Пакетall_test выбирать только для команды SF, противнику Valve/default. В команду SF
Artem заходит человеком на другого героя вместо союзного бота, играет/ставит Observer,
держит SF живым и ждёт хотя бы10с после постановки, чтобы она попала в polling.
Потом завершает запись и передаёт лог/сообщает примерное игровое время постановки.
