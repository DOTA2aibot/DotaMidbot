# ADR0012 — отдельный тест давления под T1

Proposed / T039, Issue62. Artem (GPT), reviewer Олег (Kimi).

Поручение пользователя: вместо абсолютного запрета входа под вышку оценивать прикрытие,
урон, добивание и отход; добавить переагр по присланному гайду. Контроль — v0.3.23.

В `tower_pressure_test` личный ROAM SF заменяется короткими сессиями давления под
вражеской мидовой T1. Это полная замена этого режима: нативные ROAM-походы/ганги
в данном профиле отсутствуют. В `all_test` и остальных прежних профилях ROAM остаётся Valve.
Lane/Attack/Retreat, руны, варды и доставка не заменяются.

Личный SIDE_SHOP SF в тесте возвращает0: нейтральные capture-походы отключены.
Дополнительный guard отменяет только `ability_lamp_use` или явный target
`npc_dota_watch_tower`; имена подтверждены установленными файлами игры.
Это не фильтр всех неизвестных команд C++; реальные mode arbitration/target API требуют игры.

Владелец сессии — broker.pressure. Новая сессия уступает фарму/руне/отступлению.
Внутри короткой сессии desire повышен, чтобы нативный Attack не менял направление
каждый кадр. При угрозе — состояние выхода, затем release; касты не очищаются.
Requiem/нейтральный фарм/новый ward-hook не начинают конкурировать с сессией.
Emergency BKB/ресурсы и уже идущий каст сохраняют приоритет.

Альтернатива — убрать константу750 без владельца движения — не решает конкуренцию
с нативными приказами. Риск этой схемы: новая арбитрация режимов и оценочная навигация.
Поэтому кандидат не заменяет main/установленную v0.3.23 без игрового теста.
