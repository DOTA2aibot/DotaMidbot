# ADR0006 — наблюдатель и shadow-политика перед перехватом атак

Status: **Proposed**. Связано с Issue36 / T006 / T007. Owner **Artem (GPT)**; reviewer **Олег (Kimi)**. Подтверждение решения обоими людьми не выдумывается.

Пользователь поручил добавить наблюдатель, попробовать собственные атаки при сохранении перемещений Valve, учитывать хайграунд и ставить mid wards. Во время работы уточнил: если вмешательство ухудшает модель, оно не нужно. Поэтому активная замена AA и engine modes в этой итерации отложена.

Решение-кандидат: защищённый read-only hook в существующем AbilityUsageThink собирает состояние1Hz и bounded release evidence0.1с; отдельный T007 selector выдаёт только shadow-рекомендации по прежним IDs каталога. Он не вызывает Action API. Прежние десиры/правила способностей сохранены; реальные касты/довороты журналируются отдельно. Никаких root bot/mode overrides в play нет.

Высота определяется через optional GetHeightLevel(location), не по анимационной Z-координате. Неизвестные поля остаются unknown. Uphill-разница влияет на shadow score, но этот score не является измеренной вероятностью промаха. Current/raw query урона не выдаётся за откалиброванный damage profile. Сложные combo IDs сохраняются masked, а не перенумеровываются. Ward vision не обнуляет terrain risk.

Отдельный opt-in valve_wards допускает только in-range item placement после того, как существующая ability-логика не выбрала действие, и в idle-окне Valve. Движение, атаки, смена режима, переключение dispenser, перестановка предметов и закупка не добавляются. Это ограниченный тест, не обещание расставить все предметы любой ценой. Перед экспериментальным приказом требуется работающий log sink.

JSON-схема midbot-observer-1 отделяет snapshot, shadow suggestion, submission и наблюдаемые свидетельства. Timestamp без собственного снаряда не подтверждает release. Release не является hit, расход маны/CD не подтверждает попадание. LH/kill counters дают interval attribution, не action reward. Пока нет подтверждённого combat-event/owner binding, пер-экшен labels остаются unknown.

Альтернатива — сразу заменять AA из независимого callback — отвергнута для этой итерации по уточнению пользователя. Взаимодействие с native orders и качество planner ещё не проверены. Для будущего перехвата нужны отдельный контракт арбитража и A/B-результат против замороженной рабочей базы. Не обещается нулевой overhead от наблюдателя: он измеряется в Dota.

API surface: [Bot API declarations](https://docs.moddota.com/lua_bots/), в том числе GetHeightLevel, GetLastAttackTime, tracking projectiles и item actions. Наличие объявления не подтверждает семантику installed build. Внешний код/архитектура не переносились. До независимого review и игрового прогона статус Proposed.
