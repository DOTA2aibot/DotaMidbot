# ADR0011 — ограниченное удержание линии при доставке

Статус **Proposed**, T036/Issue58, v0.3.13. Owner Artem (GPT), reviewer Олег (Kimi).

В run9082994995 замена личного ITEM-mode не решила встречу courier. Траектория SF
уходила от линии в сторону доставки в LANING/RETREAT/FARM. Внутренний C++ intent
не виден; запрещать весь RETREAT или подменять engine methods нельзя.

Тестовое решение: только all_test получает личный mode_roam_nevermore.lua с полным
GetDesire/OnStart/Think/OnEnd. Это явная замена **всего личного ROAM-mode**, без
обещания nil→C++ fallback. Нативное индивидуальное map-roaming этого режима в
all_test отключается. Lane/attack/retreat/ward/rune entrypoints не заменяются.
Предыдущий ground-only ITEM-mode сохраняется. Другие профили ROAM entry не получают.

Guard включается только возле мида при own courier alive+delivery+cargo, известной
безопасной lane anchor и наблюдённом движении SF в сторону courier **от линии**.
Приоритет.72 ниже Rune.85/Ward.80; режимATTACK/RUNE/WARD, cast/channel/queue, HP<75%,
недавний урон, видимый враг/опасная вышка/projectile запрещают вход и снимают его.
Безопасный low-mana retreat не является безусловным запретом; реальная опасность
по собственным наблюдениям выше. Отсутствие данных выключает вмешательство.

До6сек guard атакует только видимого крипа уже в attack range (один удар, не
срывать windup), иначе идёт короткими шагами до300ед к известному проходимому
lane-front. У самой anchor остаётся и ждёт доставку. Courier никогда не является
hero target. Новые угрозы/доставка/таймаут прекращают владение без ClearActions.
Вне этих условий native other modes продолжают работу, но native ROAM не возвращается
в рамках этого пакета. Возврат исходного ROAM требует чистого пакета без entry.

Это ограниченный эксперимент, а не полная копия Valve laning или доказанное
исправление любого courier detour на всей карте. Не контролируется скрытый C++
приказ; mode arbitration, passability/доставка, missed LH и gameplay надо измерить
в клиенте. В нескольких Lua-средах broker не доказывает глобальное владение.

Альтернативы: полная замена laning (больше scope/риск); только логирование (не
устраняет наблюдаемое); грубый запретRETREAT (ломает выживание). Выбран guard в
отдельном профиле. Правки рунической политики Олега (Kimi) не требуются.
Accepted/новый gameAC не заявлены. Rollback — предыдущий полный bots backup.
