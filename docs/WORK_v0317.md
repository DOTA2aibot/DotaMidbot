## Изменения

- Sentry покупается стартом независимо от наличия вручную закреплённой точки. Общая тестовая точка вычисляется из двух речных rune landmarks. Используется только если GetHeightLevel=1 и точка проходима; результат известного статического landmark кэшируется. Ошибка/отсутствие API выключает постановку, записывает причину, но не стартовую покупку. Предпочтение у явной sentry_fixed_location, если она задана.
- Расписание остаётся0:00–0:30 и6:00–6:30, запас с4:30; проверкиxx:45 до12мин. Добавлены sentry_site_state и sentry_plan_skip для понятной диагностики.
- Найден реальный дефект Raze: selector допускал радиальный край250, executor требовал210 с учётом40margin. Доворот не исправляет такой радиальный промах. Hero/creep/pack aim теперь используют одинаковый margin; фактический AoE подсчёта вторичных целей остаётся250.
- CastRaze не двигает героя ради недостижимого радиального aim. Допустимо максимум2 микрошагa за короткую серию, затем пауза0.6сек. Уже правильно направленный cast проходит сразу даже во время паузы. Успешный cast сбрасывает серию. Это ограничение приказов, не доказательство устранения каждого пропущенного удара.
- В face telemetry теперь есть ability; новый read-only raze_turn_decision показывает причину пропуска, дистанцию и индекс Raze.

Resources, Finisher, Trades, tactical config и ПТ сохранены побайтно как в подготовленной0316. Новых изменений стиков в этой итерации нет. В составе0316 уже были ранее согласованные пороги Stick7+/Wand13+, в сыгранной0315 их ещё не было.
