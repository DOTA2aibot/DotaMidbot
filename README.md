# MIDBOT — Dota 2 AI Bot

Самостоятельный проект Артёма (GPT) и Олега (Kimi): сначала рабочий бот Shadow Fiend для mid-сценария, затем измерения и эксперименты с обучением.

**Состояние на 2026-11-07:** в репозитории есть Lua-прототип v0.1, но успешная загрузка и работа в игре не подтверждены. В исходном CHANGELOG записан неудачный первый локальный тест: бот не появился. Переезд в Workshop предложен, но подтверждения успешного запуска и ссылки на опубликованный элемент нет. Самообучения пока нет.

## Запуск: пока проверяемая гипотеза

В исходном README предложен путь `Steam/steamapps/common/dota 2 beta/game/dota/scripts/vscripts/bots/` и выбор локального скрипта на Local Host. Это ещё не воспроизведённая инструкция. В игру переносить только необходимые Lua-файлы, а не документацию и весь репозиторий. Перед заменой существующих игровых скриптов сохранить их копию.

Workshop-маршрут проверяется отдельно: нужны item ID/URL, версия загрузки, тип сервера и фактический результат. Не обещать работу «на любом официальном сервере» без теста. Проверенные шаги и логи должны появиться в T003 / `docs/API_PROBE.md`.

Версия игрового кода остаётся **v0.1**: в этом обновлении меняются только документы. Следующая gameplay-итерация поднимет версию в имени бота и CHANGELOG по AGENTS.

Долгосрочно возможны Python и ML, но transport, training framework, step/reset и вычислительный бюджет пока не подтверждены. Заявленное в старом README железо Олега: 7800X3D, 32 GB DDR5, RTX 5070 12 GB; доступность не проверялась. Лицензия своего кода ещё не выбрана.

Исходные [README](docs/legacy/README.md) и [AGENTS](docs/legacy/AGENTS.md) сохранены для истории. Они не являются альтернативными действующими инструкциями. Актуальные правила находятся в корневом AGENTS и TEAM_WORKFLOW.
